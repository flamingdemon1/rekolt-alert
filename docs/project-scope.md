# Project scope

## Concept

Rekolt Alert is planned as a Creole-accessible crop early-warning assistant for Mauritian small farmers. A farmer may eventually submit crop images, explain the situation in Mauritian Creole or English, answer follow-up questions, and receive an AI-assisted preliminary risk report.

## Foundation phase

The current phase creates only the shared repository structure, ownership boundaries, proposed data contract, and planning documents.

The foundation does not include:

- a working frontend or dashboard
- a backend or API
- Gemma integration or AI logic
- voice, image-upload, weather, or alert functionality
- diagnosis, recommendation, or report generation
- production data storage

## Safety boundary

Any future result must be presented as preliminary decision support, not a guaranteed diagnosis or a replacement for qualified agricultural advice. The team must agree on safety language, escalation paths, data handling, and response-quality checks before implementation.
