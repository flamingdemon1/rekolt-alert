# Testing checklist

Owner: Manav, with each feature owner responsible for tests in their area.

This is a planning checklist; no tests or features are currently implemented.

## Before a pull request is merged

- [ ] Scope and owner are clear
- [ ] Shared contract changes were discussed
- [ ] Relevant automated tests exist and pass, once the test suite is implemented
- [ ] Ruff checks pass, once Python code is implemented
- [ ] No secret, private data, upload, or generated report is included
- [ ] Error, empty, loading, and recovery states are considered
- [ ] Keyboard use, labels, focus order, contrast, and responsive behaviour are checked where relevant
- [ ] Mauritian Creole and English paths are checked where relevant
- [ ] Safety wording does not claim a guaranteed diagnosis

## Before the demo

- [ ] End-to-end demo flow has been rehearsed
- [ ] Demo data is public and safe to share
- [ ] Failure and fallback behaviour has been rehearsed
- [ ] Required services, credentials, and network access are confirmed
- [ ] Five-minute timing is verified
