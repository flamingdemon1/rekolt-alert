# Mauritian Creole testing plan

Owner: Shihad.

Before implementation, define a small, reviewed test set covering:

- natural Mauritian Creole crop descriptions
- code-switching between Mauritian Creole, French, and English
- different spelling and phrasing for the same meaning
- ambiguous statements that require follow-up questions
- voice transcription errors and clarification
- safe handling of uncertainty and urgent situations
- consistency of warnings and recommendations across languages

Do not use private farmer information in the test set. Expected answers and safety criteria must be reviewed by the team before automated or model testing begins.
